# План расширения функционала ИВЦ ЖКХ

Предлагаю сосредоточиться на автоматизации рутинных процессов и глубокой аналитике, что принесет наибольшую пользу управляющим компаниям.

## Что будет реализовано

### 1. Интерактивный конструктор отчетов (`/reports`)
Вместо пустой заглушки создадим функциональный интерфейс для генерации отчетов.
- Библиотека шаблонов (Оборотно-сальдовая ведомость, Реестр оплат, Отчет по должникам).
- Выбор периода и фильтрация по домам/услугам.
- Предпросмотр данных перед выгрузкой в Excel/PDF.

### 2. Модуль предиктивной аналитики на Дашборде
Добавим "умные" виджеты, которые помогут предсказывать кассовые разрывы.
- График прогноза поступлений на основе исторических данных (AI).
- Анализ влияния праздничных дней и сезонности на собираемость.

### 3. Автоматизация взыскания (Расширение `/debtors`)
- Генерация PDF-уведомлений о задолженности по шаблону прямо из таблицы.
- Интерфейс настройки сценариев автообзвона и SMS-рассылок.

### 4. Умный поиск и фильтры
- Реализация расширенных фильтров в реестре должников (по сумме долга, периоду, наличию судебных решений).

## Технические детали
- Использование `Recharts` для визуализации прогнозов.
- Создание переиспользуемых компонентов для таблиц и фильтров.
- Имитация логики генерации документов (client-side PDF generation logic placeholders).

---

После реализации этих функций прототип станет полноценным рабочим инструментом, демонстрирующим ценность ИВЦ для УК.
