# План завершения реализации согласно всем предоставленным документам

На основе детального анализа всех 16 загруженных файлов (включая последние 4: Взаимодействие с ИВЦ, Обращения потребителей, Отчетность и документы, Аналитика фонда), я выявил недостающие элементы, которые необходимо внедрить для 100% соответствия требованиям.

## 1. Аналитика фонда и Дашборд (`/`)
*   **Сравнение с рынком (Benchmark)**: Добавление переключателя или визуализации отклонения от среднего/медианного значения по группе сопоставимых организаций (Benchmark).
*   **Календарь оплат**: Реализация мини-виджета "Календарь ожидаемых поступлений" с детализацией по дням (прогноз vs факт).
*   **Разрез по услугам**: Добавление возможности фильтрации дашборда по конкретной услуге (ГВС, ХВС, Электричество).

## 2. Обращения потребителей (`/requests`)
*   **Географическая тепловая карта**: Добавление визуального компонента (имитация карты) для отображения плотности жалоб по районам/домам.
*   **Аналитика каналов**: Расширение статистики по каналам связи (онлайн-чат, MAX, Госуслуги, Горячая линия).
*   **Срок обработки**: Визуальное отображение оставшегося времени до дедлайна в карточке обращения (SLA).

## 3. Взаимодействие с ИВЦ (`/tickets`)
*   **Жизненный цикл запроса**: Расширение моковых данных и UI для поддержки статусов: "Черновик", "Отправлен", "Зарегистрирован", "В работе", "Ожидается информация", "Ответ предоставлен", "Закрыт".
*   **Связанные объекты**: Улучшение интерфейса выбора связанных объектов фонда и услуг при создании запроса.
*   **Менеджер ИВЦ**: Добавление статуса доступности персонального менеджера ИВЦ в интерфейс чата.

## 4. Отчетность и документы (`/reports`)
*   **Пошаговый конструктор**: Реализация интерфейса "мастера" для создания отчета (Шаг 1: Данные, Шаг 2: Группировка, Шаг 3: Фильтры, Шаг 4: Формат).
*   **Версионность в Архиве**: Добавление индикатора версий для документов в архиве и возможности сравнения двух версий отчета.
*   **Форматы экспорта**: Поддержка визуализации выбора форматов DOCX и ZIP.

## 5. Общие системные функции
*   **Уведомления**: Интеграция уведомлений о готовности отчетов и просроченных запросах в ИВЦ в `/notifications`.
*   **Глобальный поиск**: Улучшение работы поисковой строки в шапке для поиска по всем разделам (л/с, адреса, номера запросов).

## Технические детали
*   Использование `Lucide` иконок: `Map`, `Layers`, `Timer`, `History`, `UserCheck`.
*   Добавление `Framer Motion` для анимации переходов в конструкторе отчетов.
*   Расширение структуры моковых данных в `src/lib/mock-data.ts` (если файл будет создан) или непосредственно в компонентах.
