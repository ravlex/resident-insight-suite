# Principal Insights Hub

Нужно разработать проект, изначально есть такие идеи. У нас ивц жкх. Вот цитаты идей.

"Все привет, создаю рабочий чат по новому проекту создания продукта для наших принципалов. Концепция след - продукт - это личный кабинет управляющей компании, РСО, РО или иного участника в рамках выставления платы жителю. В рамках продукта участник должен смочь получить информацию о своих взаиморасчетах с абонентами и ИВЦ.  Начислено -> Собрано -> % собираемость / Аналогично от ИВЦ, в целом должна хранится история взаиморасчетов и должна на ходу формироваться аналитика собираемости, сколько денег участнику ориентировочно ожидать сегодня, завтра послезавтра и так далее ... функционал с разной полезной аналитикой для руководства участника и управленческого персонала в рамках его фонда. Отчетность ежемесячная, возможность написать обращение в ИВЦ и получить ответ, история обращений -> в дальнейшем чат для максимально быстрого коннекта с менеджером. Различный бесплатный и платный функционал для участников ) бесплатный условно выше/ платный это возможность коммуницировать массово со своими потребителями, допустим отправлять им электронные письма с информацией) либо осуществлять автоматизированные телефонные звонки. Конструктор отчетных форм по своему фонду, подключенная АИ для помощи в работе с отчетностью. Подключение персонального менеджера для общения с потребителями в чат МАКС и ответа на их вопросы и Формирование протоколов собрания Инфографика в дашбордах, карта обращений и прочее Пока в целом до конца состава команды не понимаю, будем смотреть по обстоятельствам и думаю в ближ время поймем кто нужен и кто чем будет заниматься, пока вот так состав. Общение ведем в чате и тагаем нужных людей

Анна Гапоненко допустим так, что бы кому полагается сообщение видели - остальные могли пропустить. В личках вопросы по проекту не обсуждаем. В целом накидал вам всем начально информацию, завтра соберу и устроим мозговой штурм по проекту  - обсуждать будем концепцию и роли. По времени сообщу завтра"

"Добрый день коллеги,

Семен, в целом концепт предварительно лично для меня понятен. Хотелось бы выделить реальные боли пользователя, чтобы понимать, насколько мы закрываем потребность разработкой такого продукта и насколько эти платные фичи будут интересовать клиента, может от этих болей накидать еще идей. Чтобы спланировать то, как должен выглядеть минимальный продукт, сроки его выполнения и очередность доработки дополнительного функционала.

 

Также хотелось бы как-то подытожить, что я увидел в концепте, есть моменты которые мне пока не очень понятны, возможно стоит иметь в виду при обсуждении:

 

Разрабатываем CRM для принципалов.

Бесплатный функционал:

1. Собираемость с историчностью, масштаб: день, месяц, год, формат дашборда

2. Прогноз собираемости на основе исторических данных

3. Отчетность ежемесячная (какие-то статичные отчеты для печати, по аналогии со стек?)

4. Функционал создания обращений в ИВЦ + Реестр обращений

5. Онлайн чат для быстрого подключения менеджера

 

Платный функционал:

1. Инструмент массовой рассылки потребителям (почта, лк, смс, соц-сети?)

2. Инструмент массового обзвона

3. Конструктор отчетных форм (не очень понятно пока, что это из себя представляет)

4. ИИ помощник по работе с сервисом

5. Персональный менеджер в Макс (не очень понял как связано с сервисом)

6. ASR + LLM для протоколирования записей встреч и разговоров -> метрики по итогам собраний

7. Карта обращений (не понятно, что это)"

"Идея понятна, как часть проекта это удобная аналитика, сводка по выбранному срезу данных, рекомендации и тд. В удобном человекопонятном виде с инфографикой и тд.

Вторая часть это уже взаимодействие с нами (бухгалтерия и тд), максимально удобное и быстрое.

Третья часть пересекается с первой, но можно выделить отдельно: отчётность, конструктор отчётов, подключаем ИИ к формированию отчетов и тд.

Отдельно мы предоставим расширенную версию сервиса по подписке: рассылки (смс, почта и тд), автообзвон, персональный менеджер, AI-помощник, анализ собраний/разговоров и другие полезные инструменты типа карта обращений.

Сейчас на данном этапе нужно собрать все "боли" клиентов (ук например) и на их основе будем проектировать дальше проект."
